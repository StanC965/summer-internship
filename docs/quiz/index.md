# Interactive Quiz

Select an answer for each question and press **Check answers**. The content is loaded from the Markdown table in [work-instructions.md](data/work-instructions.md).

Progress is saved in your browser and can be viewed on the [Results page](results.md).

Optional: if you configure a submission endpoint, the first attempt result for this quiz is sent there (for example, a Google Apps Script Web App that writes to Google Sheets).

Additional static quiz from PDF: [Week 1 Review (PDF)](week1-review.md)
