# Getting Started

Use this sequence for your first day:

1. Install AVR-GCC, Microchip Studio, CMake, and `simavr`.
2. Open the project in VS Code.
3. Follow the detailed setup in [Setup GCC + VS Code](./setup-gcc-vscode.md).
4. Build `src/atmega324pb-blink` and flash to ATmega324PB Xplained Pro.
5. Start simulator debug and inspect registers, memory, and map file.
