Exercise number scheme

Exercises use the xyz scheme: means Goal x, Objective y, Exercise z (e.g. 123 = Goal 1, Objective 2, Exercise 3). Every exercise is labeled with one of three difficulty tiers:

Label Meaning How to use it
CORE Must-do — the concept cannot be understood or built upon without it Always complete these first
STRETCH Should-do if time allows — deepens understanding or extends the concept creatively Attempt after all CORE exercises of the same objective are done
OPTIONAL Nice-to-have — advanced, exploratory, or enrichment content Skip freely; come back if time permits

Counts across all 7 goals: CORE = 128 · STRETCH = 44 · OPTIONAL = 22 · Total = 194

The Additional materials (videos, articles, datasheets) are inline as collapsible FOR YOUR INFO boxes.
