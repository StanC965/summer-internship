\# Week 1 - Goal 1 - Objective 3



\## Knowing your extension board: IO1



Important note: the IO1 extension board must not be connected to the main board while the USB cable is plugged in. The USB cable must be unplugged first.



\## 131

The IO1 Xplained Pro board is an extension board that provides extra input/output components for the main ATmega324PB Xplained Pro board.



\## 132

The IO1 board contains a light sensor. This sensor can be used later as an analog input, read by the microcontroller through the ADC.



\## 133

The IO1 board contains a temperature sensor. This sensor can also be used as an analog input.



\## 134

The IO1 board contains a microSD card slot. This can be used for storage-related applications.



\## 135

The IO1 board contains a low-pass filter section. A low-pass filter allows low-frequency signals to pass and attenuates higher-frequency signals.



\## 136

The IO1 board exposes UART pins marked TX and RX. These can be used later for serial communication.



\## 137

The IO1 board also exposes GPIO pins. These can be used as general-purpose digital inputs or outputs.



\## 138

To connect the IO1 board safely, I followed this procedure:



1\. Unplug the USB cable from the PC/laptop.

2\. Connect the IO1 board to the selected EXT header of the main board.

3\. Reconnect the USB cable to the PC/laptop.



This procedure avoids connecting or disconnecting the extension board while the main board is powered.
