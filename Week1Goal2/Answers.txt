Answer: LED0 is connected to pin PC7 (PORTC, bit 7). The LED is active LOW, meaning it turns ON when PC7 is driven to GND (logic 0) and turns OFF when PC7 is driven HIGH (logic 1). 
Therefore, PC7 must first be configured as an output by setting DDRC7 = 1, then writing PORTC7 = 0 lights the LED, while writing PORTC7 = 1 turns it off.

Answer: The LEDs already have built-in series resistors on the development board. These resistors limit the current, so the LEDs can be driven directly from the microcontroller GPIO pins without adding an external resistor.

241 — CORE Why do you think it would be so much needed to organize our software program in a modular way? 
Answer: Organizing the software into modules improves readability, maintainability, and code reuse. Each module has a well-defined responsibility—for example, the gpio module handles only GPIO operations,
while main.c contains the application logic. This separation makes the code easier to understand, test, debug, and extend. It also allows the same gpio module to be reused in other embedded projects without rewriting the GPIO functions.
